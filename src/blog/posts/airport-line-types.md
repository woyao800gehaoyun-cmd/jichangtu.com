IPLC 专线机场和中转机场经常被放在同一张价格表里，但它们描述的是不同线路组织方式。选择线路时，不应只看名称，还要结合入口质量、出口地区、晚高峰拥塞和故障切换能力。

## 直连机场是什么？

直连机场通常指用户直接连接境外节点，中间没有服务方提供的国内入口中转。优点是结构简单、成本相对可控；缺点是体验更容易受到本地运营商和跨境链路波动影响。

直连不等于一定慢，也不等于一定不稳定。距离较近、网络路由合适时，直连机场可能满足轻量需求，但晚高峰表现需要实测。

## 中转机场和 BGP 机场

中转机场会先连接一个入口，再由入口转发到出口节点。这样可以对部分不稳定路径进行优化，但入口拥塞或故障也会影响整组节点。

BGP 机场通常强调入口可根据不同运营商选择或调度路径。BGP 只是网络能力的一部分，并不能单独证明最终速度。需要同时观察入口容量、出口质量和服务方调度策略。

## IPLC 机场、专线机场与内网专线机场

IPLC 常被用于描述具有专线属性的跨境连接；“专线机场”和“内网专线机场”则是更宽泛的市场表达。实际购买时应确认：

- 哪些节点或套餐真正使用所述线路；
- 入口所在地区和适用运营商；
- 故障时是否会切换到普通中转；
- 节点倍率和流量计算方式；
- 是否有明确的维护公告。

专线成本较高，但高价不自动等于高峰期稳定。对于办公或持续传输任务，故障切换和服务响应同样重要。

## 原生 IP、家宽 IP 和住宅 IP 有什么区别？

这些词描述的是出口 IP 的网络属性或数据库识别结果：

- **原生 IP 机场**：通常强调 IP 地区识别与实际出口地区一致；
- **家宽 IP 机场**：通常强调 IP 被识别为家庭宽带网络；
- **住宅 IP 机场**：通常强调住宅网络属性，但不同数据库结果可能不一致。

“原生”“家宽”“住宅”不是永久标签。同一个 IP 在不同数据库、平台和时间可能呈现不同结果。用于 TikTok、Netflix 或 AI 服务时，应以目标平台的当前识别为准。

## 如何按场景选择？

| 需求 | 可以优先测试 | 还要检查 |
| --- | --- | --- |
| 日常浏览 | 直连或普通中转 | 晚高峰、替代节点 |
| 低延迟互动 | 距离近的优质入口 | 抖动、丢包、路由方向 |
| 远程办公 | 稳定中转或专线 | 故障切换、持续连接 |
| 流媒体与地区服务 | 对应地区出口 | IP 识别、持续带宽 |
| 多地区业务 | 多入口与多出口 | 调度、规则和成本 |

没有一种线路适合所有人。建议先通过月付或试用，在自己的宽带、设备和常用时间段验证。节点倍率的成本问题可继续阅读[倍率与审计指南](/blog/airport-multiplier-audit/)，地区组合可查看[全球地区节点选择指南](/blog/airport-regional-nodes/)。
